Auto Scaling Chaos Lab

A hands-on AWS infrastructure project demonstrating automatic scaling, load balancing, lifecycle automation and event-driven server management.

View GitHub Project ← Back to Projects

Project Overview

What this project demonstrates.

The Challenge

Modern applications need to remain available when traffic changes or individual compute instances fail. Manually managing servers becomes inefficient and unreliable.

The Solution

I built an AWS Auto Scaling environment with an Application Load Balancer, lifecycle hooks, EventBridge and Lambda automation to manage instance lifecycle events.

AWS Services Used

Core AWS services used in the implementation.

Amazon EC2

Provides the compute instances running the web application.

Auto Scaling

Maintains the desired number of healthy instances and handles scaling.

Application Load Balancer

Distributes incoming application traffic across healthy EC2 instances.

Target Group

Performs health checks and manages the instances receiving application traffic.

EventBridge

Detects lifecycle events and triggers the automation workflow.

AWS Lambda

Processes the lifecycle event and performs the required automation.

Implementation

Main steps completed during the project.

01

Created the EC2 Launch Template

Configured the web application environment and instance settings used by Auto Scaling.

02

Configured the Load Balancer

Created an Application Load Balancer and target group with health checks.

03

Configured Auto Scaling

Created the Auto Scaling Group with desired, minimum and maximum capacity settings.

04

Added Lifecycle Hook

Added a lifecycle hook to pause newly launched instances before they entered service.

05

Added EventBridge Automation

Configured an EventBridge rule to detect EC2 instance launch lifecycle events.

06

Added Lambda Handler

Lambda processed the lifecycle event and completed the lifecycle action automatically.
